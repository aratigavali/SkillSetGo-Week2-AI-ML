# Skill Set Go EduTech – Week 2 AI/ML Internship

## Overview

This repository contains my Week 2 work for the **AI & Machine Learning Internship at Skill Set Go EduTech**.

During Week 2, I worked on **PyTorch, Neural Networks, CNN-based image classification, and hyperparameter experiments**.

## Tasks Completed

### Task 2.1 – PyTorch Neural Network

* Implemented a basic Neural Network using PyTorch.
* Used a **3 → 8 → 4 → 1** architecture.
* Used **Sigmoid activation** for binary classification.
* Used **BCELoss** as the loss function.
* Used **Adam optimizer** with a learning rate of `0.001`.
* Applied data normalization to improve model performance.
* Achieved **100% accuracy** after training.

### Task 2.2 – CNN Image Classifier

* Implemented a **Convolutional Neural Network (CNN)** using PyTorch.
* Used the **CIFAR-10 dataset** for image classification.
* The model contains convolutional, pooling, and fully connected layers.
* Used **CrossEntropyLoss** and the **Adam optimizer**.
* Achieved approximately **72.22% accuracy after 5 epochs**.

### Task 2.3 – Hyperparameter Experiment

Experimented with different learning rates to understand their effect on CNN performance.

| Learning Rate | Accuracy |
| ------------- | -------: |
| 0.001         |   69.40% |
| 0.01          |   10.00% |
| Experiment    |   67.55% |
